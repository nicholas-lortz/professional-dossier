## Engineering Notes

### Atomic Number — `Z`

The atomic number is the number of protons in the nucleus and uniquely identifies an element.

### Mass Number — `A`

For an individual isotope:

$$
A = Z + N
$$

where:

- `A` = mass number
- `Z` = number of protons
- `N` = number of neutrons

### Atomic Weight

Values without brackets represent standard atomic weights.

Values in **square brackets** represent the mass number of a representative isotope for elements that do not have a standard atomic weight because they have no stable isotopes.

### Material Specification

Elemental composition should **not** be used as a substitute for a material specification.

When identifying an engineering material, use the applicable:

- Material standard
- Grade
- Alloy designation
- Temper
- Heat treatment
- Condition
- Product form
- Applicable specification or drawing requirement

For example, identifying a material simply as **Fe-C** is insufficient to specify a steel for production use.
