# Reading the Micrometer

A practical guide to the inch-series outside micrometer ("mike"): how it works, how to hold it, and how to read it to the thousandth of an inch.

> **Resolution:** 0.001" (one thousandth) | **Thread pitch:** 40 threads per inch | **One thimble turn:** 0.025"

---

## Parts of the Micrometer

| Part | Function |
|---|---|
| **Frame** | C-shaped body that holds everything in alignment; keep your fingers off it when possible, since body heat expands the metal |
| **Anvil** | Fixed measuring face at the end of the frame |
| **Spindle** | Moving measuring face; it advances and retracts as the thimble turns |
| **Barrel (sleeve)** | Stationary cylinder carrying the main scale (the linear graduations) |
| **Thimble** | Rotating sleeve with the 25-division scale; turning it moves the spindle |
| **Ratchet stop** | Slip-clutch knob at the end; gives consistent measuring pressure |
| **Lock nut** | Locks the spindle in place so a reading can be held while you remove the mike |

---

## How It Works

The spindle is driven by a precision screw with **40 threads per inch**.

- One full turn of the thimble moves the spindle **1/40 in = 0.025 in**.
- The thimble face is divided into **25 equal parts**.
- Each thimble division is therefore 0.025 ÷ 25 = **0.001 in**.

The barrel is marked to match:

- One scribed line = **0.025 in** (one thimble turn).
- Every **4th line** is numbered. Four lines × 0.025 = 0.100, so each number is **one-tenth of an inch (0.100 in)**.
- Four complete turns from zero show the number **1** on the barrel (0.100 in). Ten numbered tenths make a full inch.

---

## The Three-Step Reading Method

Take **three readings** and add them: two from the barrel and one from the thimble.

| Step | What to read | Value |
|---|---|---|
| **1** | Largest **number** visible on the barrel | number × **0.100 in** |
| **2** | Number of **extra lines** visible past that number | lines × **0.025 in** |
| **3** | Thimble line that **lines up with the barrel's horizontal index line** | divisions × **0.001 in** |

**Reading = Step 1 + Step 2 + Step 3**

```
Reading = (barrel number × 0.100) + (extra lines × 0.025) + (thimble divisions × 0.001)
```

Accuracy in reading the mike is just as important as taking the measurement itself.

## Worked Examples

### Example 1: The reference reading (.225")

From the information sheet's parts illustration (barrel shows 0 1 2, thimble at 0):

| Step | Observation | Value |
|---|---|---|
| 1 | Barrel number **2** | 0.200 |
| 2 | **1** extra line past the 2 | 0.025 |
| 3 | Thimble reads **0** | 0.000 |
| | **Total** | **0.225 in** |

### Example 2

Barrel shows **3**, **2** extra lines visible, thimble line **13** aligns with the index line.

```
0.300 + 0.050 + 0.013 = 0.363 in
```

### Example 3: Thimble has passed zero

Barrel shows **1**, **no** extra lines, thimble line **7** aligns.

```
0.100 + 0.000 + 0.007 = 0.107 in
```

### Example 4: Reading near the edge

Barrel shows **5**, **3** extra lines visible, thimble line **24** aligns.

```
0.500 + 0.075 + 0.024 = 0.599 in
```

> **Check:** if the thimble edge is *just* uncovering a barrel line, the thimble reading should be near 0 (or near 24 if the line is barely covered). A mismatch between the two means you miscounted a line.

## Reading Larger Micrometers (2"-6")

Larger micrometers use the **same barrel and thimble scales** (still 0.001 in resolution). What changes is the **measuring range**: each size starts where the previous one ends. The frame is longer, but the screw still only travels 1 inch.

| Mike size | Range | Add this base to the scale reading |
|---|---|---|
| 1" | 0-1" | + 0.000 |
| 2" | 1-2" | + 1.000 |
| 3" | 2-3" | + 2.000 |
| 4" | 3-4" | + 3.000 |
| 5" | 4-5" | + 4.000 |
| 6" | 5-6" | + 5.000 |

**Procedure:** read the barrel and thimble exactly as for a 1" mike, then add the base for the mike's size.

**Example:** on a **3" mike**, the scale reads 0.363 in:

```
2.000 + 0.363 = 2.363 in
```

Larger micrometers are usually checked against a **standard (gauge rod)** to set zero, since the anvil and spindle don't meet at 0 on mikes bigger than 1".

## How to Hold and Use a Micrometer

1. **Clean** the anvil, spindle face, and the part. Dirt and oil add error.
2. **Hold the frame** in the palm of your hand, with the thumb and forefinger free to turn the thimble (see the "How to hold" illustration in the original sheet).
3. **Open** the mike wider than the part, then slide the part between the faces.
4. **Close** the spindle using the thimble until the faces are near contact.
5. **Finish with the ratchet stop.** Turn it until it clicks 2 to 3 times. This applies consistent pressure and prevents over-tightening.
6. **Read** the mike. If it's hard to read in place, tighten the **lock nut**, carefully slide the mike off, then read.
7. **Re-check** the reading, especially the barrel count.

### Care and storage

- Check the **zero** (close the faces on a clean surface with the ratchet) before measuring.
- Don't store the mike fully closed; leave the faces slightly apart to avoid corrosion and stress.
- Never drop it or use it as a clamp. Wipe it clean and lightly oiled after use.
- Let the mike and the part reach the same temperature before measuring.

## Common Mistakes

| Mistake | Fix |
|---|---|
| Forgetting an extra barrel line (off by 0.025) | Count the lines past the number every time |
| Reading a number that's partly hidden by the thimble | Use the last number *fully* visible |
| Cranking the thimble directly | Use the ratchet stop for the last bit |
| Misreading the thimble (off by 0.010 or 0.020) | Note the numbered thimble marks (0, 5, 10, 15, 20) and count from the nearest one |
| Forgetting the size base on 2"+ mikes | Always add the base: 1.000 for 2", 2.000 for 3", and so on |
| Taking a reading from an angle | Look straight at the index line to avoid parallax |

## Quick Reference Card

```
1 thimble division  = 0.001"
1 barrel line       = 0.025"   (= 25 thimble divisions = 1 full turn)
1 barrel number     = 0.100"   (= 4 barrel lines)
1 inch of travel    = 40 turns = 10 barrel numbers

READING = barrel number x 0.100
        + extra lines   x 0.025
        + thimble       x 0.001
        + size base (0, 1, 2, 3, 4, 5 in for 1"-6" mikes)
```

### Memory aid

> **"Hundreds, quarters, ones."** Barrel number is hundreds of thousandths, extra lines are 25-thousandths (quarters of 0.100), thimble gives the single thousandths.
